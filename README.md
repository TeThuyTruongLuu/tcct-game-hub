# 🎮 TCCT Game Hub

A **non-profit web game hub** built by **Phong**.  
This project is created as a **playground for the Vietnamese fandom of Toàn Chức Cao Thủ (全职高手)**.  
The goal is to make a fun, lightweight space where fans can enjoy multiple mini games, track scores, and share challenges together.

## ✨ Features
- 🔑 **Login / Guest Mode**  
  Save your progress with Firebase authentication or play instantly as a guest.
- 🏆 **Leaderboards & Scoreboards**  
  Track your own progress or compete with others on the global leaderboard.
- 🎲 **Game Collection**  
  Includes: 2048, Onet (Tile Matching), Battleship, Sliding Puzzle, Sorting, Nonogram, Memory Flip, Puzzle, Random Tools, Story/Images Storage and more.
- 📅 **Timeline & Project Updates**  
  Built-in timeline view and Google Sheets embed for event tracking (e.g., *Noletuban Project*).
- 👤 **Character & Quotes**  
  Choose avatars, add custom quotes, and personalize your experience.

---

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, Vanilla JavaScript  
- **Backend / Cloud:** Firebase (Auth, Firestore, App Check)  
- **Embedded Data:** Google Sheets
